# Autoeletric

Site de uma loja virtual fictícia de veículos autopropelidos elétricos e acessórios, com compra online e retirada presencial em Curitiba/PR.

**Funcionalidades:** catálogo com busca, filtro e ordenação; carrinho com limite de estoque; cadastro (somente maiores de 18 anos) e login; resumo da compra; acompanhamento do status do pedido; páginas de retirada e regras de circulação (CONTRAN 996/2023); botão de modo claro/escuro; vídeo institucional e áudio com dicas de segurança na página Sobre.

**Tecnologias:** HTML5, CSS3, JavaScript e Bootstrap 5.3. Os dados ficam no `localStorage` do navegador, sem servidor.

**Como usar:** abra o `index.html` no navegador. A documentação completa está na pasta `doc/`.
