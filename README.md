# Autoeletric
Loja virtual de veículos autopropelidos elétricos (patinetes, e-bikes, scooters) e acessórios, com compra online e retirada em Curitiba. Catálogo com filtros, carrinho com controle de estoque, cadastro 18+, login e status do pedido. Feito com HTML, CSS, JavaScript e Bootstrap.

Site de uma loja virtual fictícia de veículos autopropelidos elétricos e acessórios, com compra online e retirada presencial em Curitiba/PR. Projeto acadêmico de Beatriz Vieira dos Santos e João Vitor Rodrigues Araújo.

**Funcionalidades:** catálogo com busca, filtro e ordenação; carrinho com limite de estoque; cadastro (somente maiores de 18 anos) e login; resumo da compra; acompanhamento do status do pedido; páginas de retirada e regras de circulação (CONTRAN 996/2023).

**Tecnologias:** HTML5, CSS3, JavaScript e Bootstrap 5.3. Os dados ficam no `localStorage` do navegador, sem servidor.

**Como usar:** abra o `index.html` no navegador. A documentação completa está na pasta `doc/`.
